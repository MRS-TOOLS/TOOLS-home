# MRS TOOLS

## 📦 公開ツール一覧
このリポジトリには、各ツールの公開用フォルダがまとめられています。

- counter  
- dice-coin  
- gb-dialy  
- jan-code-reader  
- metronome  
- qr-maker  
- stopwatch  
- timer  
- waste-log  

## 🔧 開発方針
- 新規ツールは個人アカウントで単独リポジトリとして開発  
- 安定板になったら MRS-TOOLS Organization に移動  
- このリポジトリは “公開用フォルダの棚” として運用
